# AI 찾기 마스터

Build AIAtlas.kr, a Korean-first AI tool discovery, comparison, and practical-use platform specifically designed for the South Korean market.

This is NOT simply an English AI directory translated into Korean.

AIAtlas.kr should be designed from the beginning around the needs, search behavior, work environment, content platforms, businesses, and everyday use cases of Korean users.

1. CORE CONCEPT

Brand:

AIAtlas.kr

Positioning:

한국인을 위한 AI 도구 검색·비교·활용 플랫폼

Main slogan:

나에게 맞는 AI를 쉽게 찾다

Secondary slogan:

AI 도구를 찾고, 비교하고, 실제로 활용해보세요.

Core user journey:

찾기 → 비교하기 → 선택하기 → 활용하기

AIAtlas.kr should become a practical starting point for Koreans who want to use AI but don't know:

어떤 AI를 사용해야 하는지

무료인지 유료인지

한국어를 잘 지원하는지

어떤 작업에 적합한지

ChatGPT와 Claude 중 무엇이 좋은지

어떤 AI가 블로그에 좋은지

어떤 AI가 유튜브/쇼츠에 좋은지

어떤 AI가 업무에 좋은지

어떤 AI가 자영업이나 온라인 사업에 도움이 되는지

3. IMPORTANT DIFFERENTIATION

AIAtlas.kr should NOT compete simply by having the largest number of AI tools.

Instead, differentiate through:

① 한국 사용자 중심

Explain AI tools from the perspective of Korean users.

② 실제 활용 목적 중심

Users should be able to search:

"블로그 글 써주는 AI"

"유튜브 쇼츠 만드는 AI"

"무료 이미지 생성 AI"

"스마트스토어 상품 설명 만들어주는 AI"

"엑셀 분석하는 AI"

"PDF 요약하는 AI"

rather than only searching by AI tool name.

③ 한국어 지원 정보

Every AI tool should indicate:

한국어 지원

한국어 UI

한국어 입력 가능

한국어 결과 품질

한국어 음성 지원 where applicable

④ 무료 사용 가능 여부

Clearly show:

완전 무료

무료 플랜

무료 체험

유료

크레딧 방식

⑤ 한국 사용자에게 실제로 도움이 되는 활용법

Each tool should explain:

"한국에서는 이 AI를 어디에 사용할 수 있는가?"

26. MOST IMPORTANT REQUIREMENT

Do NOT simply create a Korean translation of an international AI directory.

Build AIAtlas.kr as a Korean AI discovery service.

The key question throughout the product should be:

"한국 사용자가 어떤 AI를 찾고 있으며, 실제로 무엇을 하려고 하는가?"

The website should help a user go from:

"AI가 뭔지는 알겠는데 어떤 걸 써야 하지?"

to:

"아, 이 작업에는 이 AI를 쓰면 되는구나."

AIAtlas.kr should ultimately become:

한국에서 AI를 처음 찾을 때 가장 먼저 방문하는 사이트.
